22. RESOLUTION OF VERIFIER BOUNDARY REJECTION & LIVE ON-CHAIN SETTLEMENT
====================================================================================================

Root Cause Analysis:
  - User reported rejection: "INVALID_REQUEST * Detail: Basket lines count must be between 1 and 16"
  - Cause: An old mandate persisted in local storage with `perPurchaseCap: $15.00`. When the agent
    optimized a requirement requiring $22.59, no basket line could be funded without exceeding $15.00.
    The optimizer returned `lines = []`, which triggered the verifier boundary check `1 <= len(lines) <= 16`.
  - Fixes Implemented:
